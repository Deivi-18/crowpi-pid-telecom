## 🎯 Descripción

Sistema de control PID para aplicaciones de telecomunicaciones en CrowPi. Controla la potencia de transmisión manteniéndola en un valor deseado usando algoritmo PID con protección Anti-Windup.

## 🚀 Características

- Control PID completo (P, I, D)
- Protección Anti-Windup
- Lectura ADC MCP3008 via SPI
- Salida PWM por GPIO18
- Cambio dinámico de setpoint
- Ajuste en tiempo real de parámetros

## 🛠️ Hardware Requerido

- CrowPi con Raspberry Pi
- Sensor conectado a ADC MCP3008
- Actuador controlado por PWM
- Conexiones SPI activadas
